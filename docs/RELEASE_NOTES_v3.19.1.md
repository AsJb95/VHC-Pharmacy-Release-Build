# VHC Pharmacy POS v3.19.1

This stable update fixes the Reports Bill Count for Split Payments. Bill Count now counts distinct bills instead of payment rows. Split payment rows and payment totals remain unchanged; `Transactions: N` still counts payment rows. For example, 63 sales with 65 payment rows show Bill Count 63.
